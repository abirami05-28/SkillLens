FAQs

1. What is SkillLens? +
SkillLens is an AI-powered recruitment assistant that streamlines resume screening, candidate profiling, and interview scheduling.
2. How does SkillLens ensure fairness? +
We use IBM’s AIF360 toolkit to detect and mitigate biases in candidate scoring, ensuring fair opportunities for all applicants.
3. Do recruiters need technical knowledge to use it? +
Not at all! SkillLens provides an intuitive dashboard and filtering options so recruiters can focus on hiring decisions, not tech.
4. Can SkillLens integrate with existing ATS systems? +
Yes, SkillLens APIs can connect seamlessly with popular Applicant Tracking Systems.
5. Is candidate data secure? +
Absolutely. We prioritize data privacy and comply with global security standards like GDPR.
6. How is interview scheduling automated? +
Our platform syncs recruiter calendars (Google, Outlook) with shortlisted candidates to automate booking.
